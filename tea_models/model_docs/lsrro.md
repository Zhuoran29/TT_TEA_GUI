# LSRRO Model Documentation

## Scope

The LSRRO unit is implemented as a train-connected desalination model. It uses
the inlet stream flow and water-quality profile passed from upstream units. It
does not read a separate feed-water file.

## Technical Model

Water recovery is a manual input. The default recovery rate is 0.5.

The model also reports a calculated recovery reference from an empirical
regression based on the Atia et al. 2023 PBSE/WaterTAP LSRRO framework with the
NMPWRC high-salinity produced water correction:

```text
TDS_g_L = feed TDS / 1000
Recovery_base_percent = -0.0002*TDS_g_L^2 - 0.3816*TDS_g_L + 84.01
Recovery_percent = Recovery_base_percent - 0.000369*Hardness - 0.0001*Silica
```

Hardness is in mg/L as CaCO3 and silica is in mg/L. The calculated reference
recovery is clipped to 1-90%, but the train water balance uses the manual
`recovery` input.

The stage count and operating pressure are selected from the NMPWRC LSRRO
TDS design-point table; `stage_override` and `pressure_override_psi` can
overwrite those lookup values.

Electrical demand uses the NMPWRC LSRRO experimental pump-power basis:

```text
gross_power = reference_gross_power * inlet_flow_bbl_day / reference_flow_bbl_day
net_power = gross_power * (1 - energy_recovery_fraction)
energy_intensity = net_power * 24 / inlet_flow_m3_day
```

## Water-Quality Model

Permeate concentrations are calculated from the LSRRO water-quality model:

- Direct regressions are used for alkalinity, ammonia nitrogen, BTEX, calcium,
  and chloride.
- Average or surrogate removals are used for TDS, TOC, TSS, conductivity,
  hardness, barium, boron, magnesium, silica, sodium, strontium, iron, sulfate,
  gross alpha, gross beta, radium-226, radium-228, oil, TPH, and PAHs.
- pH and temperature are passed through unchanged when present.
- Negative regression predictions are clipped to zero by default.

The brine water-quality stream is generated by constituent mass balance from
the inlet and predicted permeate streams.

## Cost Model

The cost model returns installed capital cost and annual operating cost only.
The treatment-train framework applies the project CRF and calculates LCOW once
at the train level.

Reference assumptions:

- Reference flow: 50,000 bbl/day
- Reference direct membrane CAPEX: $20.5 million, treated as 2024 dollars when
  no explicit source year is available
- CAPEX scaling exponent: 0.81 from the NMPWRC empirical LSRRO scale-up
  correlation
- Gross pump power: 3,534 kW
- ERD fraction: 30%
- Antiscalant dose: 3 mg/L
- Antiscalant price: $61.40/gal, source year 2026
- CIP cost: $0.07/m3 product, source year 2021
- Membrane replacement: 20% of direct membrane CAPEX per year
- O&M contingency: 20%
